青龙签到脚本 · 登录信息获取手册

Cloud-Drive-Check-in ｜ 20 个凭证变量 ｜ 18 个平台
Cookie 类通用步骤：电脑浏览器登录目标网站 → F12 → 「网络 / Network」→ 刷新页面 → 点任意一条目标域名请求 → 复制「请求标头」里 cookie: 冒号后的全部内容。
多账号：每个账号各抓一份，同一变量内各占一行（换行分隔），值不要加引号。

☁️ 云盘类

ALIYUN_REFRESH_TOKEN阿里云盘⚠ 不是 Cookie
  1. 浏览器登录 aliyundrive.com
  2. F12 →「应用 / Application」→ 本地存储 → 选该域名
  3. 找键 token，从 JSON 里复制 refresh_token 长字符串
  4. 只贴字符串本身，不带 Cookie: 前缀
BAIDU_COOKIE百度网盘

登录 pan.baidu.com 后按通用步骤抓 Cookie。

QUARK_COOKIE夸克网盘

登录 pan.quark.cn 后按通用步骤抓 Cookie。

TY_USERNAME / TY_PASSWORD天翼云盘

免抓包，直接填 cloud.189.cn 的手机号 + 密码。多账号两变量用 & 分隔、按位置一一对应。

🚇 生活服务类

sfsyUrl顺丰速运⚠ 变量名全小写
  1. 手机配代理（Charles / Fiddler / HttpCanary）抓 weixin.sf-express.com
  2. 任意请求 URL 里找 token= 参数（一长串含 URL 编码）
  3. 整段复制为变量值，多账号换行
CDRAIL_DATA成都地铁
  1. 抓 App 包，域名 scdcmtyzapp，进"积分"页触发请求
  2. 从请求头取 token、app-token、Cookie 三个值
  3. 拼成一行 JSON：{"token":"..","app-token":"..","Cookie":".."}，多账号换行或 @
tsthbck塔斯汀汉堡⚠ 变量名全小写
  1. 电脑微信小程序 + Charles/Fiddler 抓包
  2. 过滤域名 sss-web.tastientech.com
  3. 复制请求头里 user-token 的值（不是整串 Cookie）
SMZDM_COOKIE什么值得买

登录 www.smzdm.com 后按通用步骤抓 Cookie。

💬 论坛 / 社区类

enshan_cookie恩山论坛⚠ 变量名全小写

登录 www.right.com.cn 抓 Cookie，勾选"记住登录"延长有效期。

TIEBA_COOKIE百度贴吧

登录 tieba.baidu.com 抓 Cookie，必须含 BDUSS= 字段；最少可只留 BDUSS=..; STIN=..。

NGA_CREDENTIALSNGA 论坛
  1. 登录 bbs.nga.cn → 设置 → 账号安全页
  2. 找到 UID（数字）与 AccessToken（授权码）
  3. 每行按 UID,AccessToken 格式填写（英文逗号）
HiFiTi_COOKIE / HIFIHI_COOKIEHiFiNi⚠ 混合大小写

分别登录 hifini.com 与第二站点抓 Cookie，玩哪个站配哪个，两变量独立。

🛜 NAT / 机场 / 节点类

NODESEEK_COOKIENodeSeek

登录 nodeseek.com 抓 Cookie。Cloudflare 风控站，青龙需装 curl_cffi。

DEEPFLOOD_COOKIEDeepFlood

登录论坛抓 Cookie。同为 Cloudflare 风控站，需 curl_cffi。

PASSNAT_SKPassNAT

免抓包：登录 passnat.com 后台 →「API / 密钥」页 → 复制 sk 开头的密钥。

IKUUU_EMAIL / IKUUU_PASSWDikuuu

免抓包：控制台（ikuuu.nl / .de / .la）的注册邮箱 + 密码。多账号两变量各自换行、位置一一对应。

LEAFLOW_COOKIELeaflow⚠ 必须用新版控制台

登录 console.leaflow.net 抓 Cookie，确认含 leaflow_session= 和 XSRF-TOKEN= 字段；旧站 checkin.leaflow.net 的 PHPSESSID 已失效。

🔒 Cookie / token / 密码等同账号密码，只填进青龙面板，勿外传、勿提交仓库　｜　🔄 报「登录失败 / 403」多为凭证过期，重抓替换即可（顺丰 / 塔斯汀 / 成都地铁掉线最快，账密类长期有效）　｜　⏸ 暂不玩的平台，把变量「禁用」脚本即自动跳过　｜　✅ 抓取前先确认浏览器处于登录态
